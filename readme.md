# 🟠 Norix

**Your personal AI assistant.**

Norix is a desktop AI assistant developed by **Norix Studios**.

## ✨ Features

* 🤖 AI assistant
* 🎤 Voice interaction
* 🔊 Text-to-Speech
* 🖥️ Modern desktop interface
* 🔽 System Tray
* ⚡ Background mode
* 🪟 Windows support

## ⚠️ Windows Security Notice

Norix is currently a new and unsigned application. Windows may display a security warning when starting Norix because the application does not yet have a digital signature or established reputation.

Only download Norix from the official Norix repository and releases.
